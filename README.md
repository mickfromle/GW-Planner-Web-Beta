# GW Planner Web Beta

A standalone browser beta of the GW Planner for iPhone, iPad, Mac, Android and desktop browsers.

The web beta intentionally contains only Planner functionality. It does not include Point Checker, overlay, billing, PRO or the normal GW Tactics home/settings screens.

Current web beta features:
- Tuesday–Sunday planning, weeks 1–4
- Team sizes 3v3–10v10 or break
- Player editor with country, real time zone/region, role, PvP strength, preferred local play window and Spare preference
- Per-week availability
- Max. two GW days per player
- 18 attacks per player
- PvP/PvZ/spare allocation and concrete stacking targets
- MAP / PLAYERS / TIMELINE previews
- Selectable day/week screenshot export
- Browser-local storage

The GitHub Pages workflow publishes the contents of this directory.
